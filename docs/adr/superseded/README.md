# Superseded designs

This directory keeps designs that a later decision record replaced, so their research never has to be repeated.

The Linux and Cozystack plan of 7 September 2026 (`ZD-CLOUD-MASTER-PLAN.md`, delivered separately) is superseded by ADR 0002. It is kept so that, if the owner ever reverses ADR 0002, the research does not have to be repeated. Copy it here on import.
